# Project Images

Drop the following image files into this folder (`public/`) to display them on the project cards. Recommended size: **800×400px** or any 2:1 aspect ratio. Formats: `.jpg`, `.png`, or `.webp`.

| File name | Used for |
| --- | --- |
| `stellar-tales.jpg` | Stellar Tales (NASA Space Apps 2025) — first card |
| `skilldev.jpg` | SkillDev — second card |
| `lost-found.jpg` | Lost & Found Portal — third card |
| `cashnex.jpg` | CashNex — fourth card |

If a file is missing, the card will show a gradient placeholder with a GitHub icon instead of a broken image.

After dropping the files in, **hard refresh** the browser (`Ctrl+Shift+R` / `Cmd+Shift+R`) to clear the Next.js dev cache.
